# MultiplayerDeck 联机Mod说明文档

## 一、玩法改动

1. 所有玩家共用相同的地图。
2. 当有玩家进入战斗 / Boss 战斗时，所有玩家进入相同的战斗。
3. 进入下一层时，所有玩家进行投票，投票通过后进入下一层。
4. 战斗开始时，将所有玩家的卡组合成为一个大卡组。所有玩家都将从这个大卡组中抽牌，打出的牌将进入一个共用的弃牌库，同步所有玩家的抽牌库和弃牌库。
5. 抽取到其他玩家的技能时，将技能持有者改为随机一个玩家自己的调查员，优先是和原持有者相同职业的调查员。
6. 敌方血量根据玩家人数翻倍，同步敌方血量。
7. 同步时间轴，但由于敌人回合开始时倒计时有一定随机，玩家间的敌方倒计时并不完全相同。
8. 使用交换时，被交换的技能不进入弃牌库，而是加入随机一个其他玩家的手牌中。
9. 所有玩家结束回合后，进入下一回合。

## 二、联机技能

1. 使用联机技能可以为其他玩家提供效果，类似于尖塔的联机卡牌。
2. 新增基类 `SkillExtended_Network`，其继承自 `Skill_Extended`，可以利用其更简便地扩展新的联机技能。以下称使用联机技能的玩家为**主机**，其他收到联机技能效果的玩家为**客机**。
3. 重写 `RemoteSkillEffect` 方法可以实现客机收到的技能效果，参数 `Targets` 为技能目标：
   - 当主机技能目标为敌方时，`Targets` 为客机对应的敌人；
   - 当主机技能目标为友方时，`Targets` 为客机对应位置的调查员。
4. 调用 `AddCustomNumbers` 可以添加自定义数值，参数 `reset` 表示是否清除已有的自定义数值。`RemoteSkillEffect` 方法中可以通过 `CustomNumbers` 列表读取自定义数值。通过自定义数值，可以根据主机的战斗情况更改给客机的效果。推荐重写 `LocalSkillEffect` 方法添加自定义数值。
5. 默认在 `SkillUseSingle` 方法中调用 `LocalSkillEffect` 和 `SendSkillEffect`，即效果默认在技能使用时生效。如果想在其他时点生效，可以重写 `SkillUseSingle` 禁用默认的调用，然后在合适的时点调用 `AddCustomNumbers`、`LocalSkillEffect`、`SendSkillEffect` 方法。

## 三、使用方法

1. 按下 `F` 键可开关联机面板。
2. 一位玩家创建房间，其他玩家可以通过面板加入房间；如果没有房间，可以刷新一下，也可以通过 Steam 邀请加入房间。
3. 所有玩家均在房间后，可以各自正常选人，选人完毕后所有玩家投票进入迷雾庭院。
4. 下层需要在面板投票。结束回合可以正常点击“结束回合”或者按 `Q` 键，也可以在面板投票，但是取消结束回合需要在面板取消。
5. 关于进入荒野 / 扎师傅：所有玩家开启荒野门 / 放入项链后，会新开启一个进入荒野 / 扎师傅的投票，选择即可。
6. 理论上支持读档。所有玩家在主界面重新建房、加入房间后，各自读档即可。

## 四、已知问题

1. 由于浑圆的奇妙代码，原版如果卡住无法操作，在大约 7 秒后会恢复可操作状态。所以现在玩家在结束回合但不是全部玩家都结束了回合时，虽然会短暂锁定手牌，但在大约 7 秒后会解锁，也就是可以在按下结束回合后继续操作（。
2. 进入战斗时，若有玩家在事件、商店等其他界面，会在关闭界面后再进入战斗以避免异常。但如果在界面待得过久，会触发超时机制而使用本地卡组，不再同步大卡组。
3. 没有添加对游戏失败的处理。理论上现在一个玩家在战斗中团灭，会导致该玩家直接游戏结束；之后由于该玩家层数不同步，将无法再次加入联机。
4. 没有测试与其他 Mod 的兼容。理论上所有玩家开启相同的角色 Mod 时，可以游玩 Mod 角色。同时，部分机制类 Mod（例如开发者模式、生活质量、卷轴无需鉴定、View Deck等）不会与联机冲突。但在测试中，有时（有时……）开启 Mod 会导致 `BattleSystem.BattleStart` 的 `Postfix` 不进入，导致战斗开始时合成大卡组失败，原因暂不明，也没有找到具体什么 Mod 会影响。（不过至少测试时开发者模式是一直开着的）
